# 매일성경 읽기표 확인

날짜별 매일성경 묵상에 사용할 본문을 정할 때 읽는다. 사용자가 본문을 직접 지정했다면 날짜 조회는 필요하지 않다.

## 공식 경로

[성서유니온 오늘의 묵상](https://sum.su.or.kr:8888/bible/today)을 연다. 매일성경, 매일성경 순, 청소년 등 사용자가 요청한 교재를 선택한다. 교재 지정이 없으면 매일성경을 사용한다.

매일성경의 날짜별 페이지에는 다음 형식으로 접근할 수 있다.

```text
https://sum.su.or.kr:8888/bible/today?base_de=YYYY-MM-DD&qt_ty=QT1
```

`base_de`에 필요한 날짜를 넣는다. `qt_ty=QT1`은 매일성경 선택값이다. 링크를 열었다고 그 날짜가 선택되었다고 가정하지 말고, 페이지 본문에 표시된 날짜와 성경 범위를 확인한다. 다른 교재의 선택값은 해당 페이지에서 확인하며 추측하지 않는다.

## 확인할 항목

페이지에 표시된 교재명, 연월일, 본문 범위를 확인한다. 본문 범위는 장과 절의 시작과 끝을 모두 기록한다. 찬송가 번호나 해설 제목을 성경 구절로 오인하지 않는다.

HTML을 읽는 경우 `script`와 `style`의 내용을 제외한 실제 본문을 확인한다. 스크립트에 들어 있는 문자열 템플릿을 본문 범위로 잘못 읽지 않는다. 달력에 표시된 월과 묵상 본문의 날짜가 다른지도 확인한다.

조회한 날짜가 맞으면 사용자에게 해당 날짜와 본문 범위, 날짜가 포함된 공식 링크를 제공한다. 묵상 제목은 본문에 맞게 작성할 수 있으며, 성서유니온 해설의 제목을 사용할 필요는 없다.

## 페이지를 읽을 수 없을 때

[성서유니온 홈페이지](https://su.or.kr/)에서 매일성경과 오늘의 묵상 메뉴를 찾아 공식 경로를 확인한다. 검색을 사용할 때에는 성서유니온 도메인과 정확한 날짜를 포함한다. 접근할 수 있는 공식 읽기표나 해당 날짜의 공식 콘텐츠에서 본문을 확인한다.

다른 기관이 운영하는 성경 묵상 일정과 성서유니온 매일성경의 일정을 구별한다. 검색 결과의 일부 문구, 전년도 같은 월일, 개인 블로그의 게시 날짜만으로 해당 연도의 본문을 결정하지 않는다.

공식 경로에서 날짜와 본문을 확인할 수 없으면 필요한 구절 범위나 읽기표를 사용자에게 요청한다. 사용자가 본문을 제공하면 그 범위로 묵상하고, 공식 일정의 확인 여부가 필요한 경우에만 해당 사실을 짧게 밝힌다.
